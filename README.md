# Insurance EDA Project

This project performs Exploratory Data Analysis (EDA) on an insurance dataset to uncover trends and insights related to customer demographics, insurance charges, and health habits.

## Objective

To analyze how factors such as age, sex, BMI, smoking habits, and number of children influence insurance charges.

## Tools Used

- Python  
- Jupyter Notebook  
- Pandas  
- NumPy  
- Matplotlib  
- Seaborn  

## Dataset

The dataset contains customer-level information:
- Age  
- Sex  
- BMI (Body Mass Index)  
- Number of Children  
- Smoker (Yes/No)  
- Region  
- Insurance Charges  

## Key Steps & Insights

- *Data Cleaning*: Checked for missing values (none in this dataset).
- *Data Types*: Verified numerical and categorical variables.
- *Univariate Analysis*: Distribution plots for all variables.
- *Bivariate Analysis*:
  - Smokers pay significantly higher charges.
  - Charges increase sharply with age and BMI.
  - Male and female distribution is fairly balanced.
- *Correlation Heatmap*: Charges highly correlated with age and smoking.

## Visuals

- Heatmaps
